# SCT_SD_Task1 - Temperature Converter

A user-friendly web application that converts temperatures between Celsius, Fahrenheit, and Kelvin scales.

## Features

- Convert temperatures between Celsius, Fahrenheit, and Kelvin
- User-friendly interface
- Swap source and target temperature units
- Input validation
- Responsive design
- Accurate temperature conversion

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Enter a temperature value.
2. Select the source temperature unit.
3. Select the target temperature unit.
4. Click **Convert Temperature**.
5. View the converted temperature.
